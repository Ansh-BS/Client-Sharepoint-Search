What all three hold to

  • PRODUCT.md's anti-references: no gradient text, no hero metrics, no tracked-uppercase eyebrows, no purple-gradient decoration.
  • Every state teaches. No match, no link, and duplicate ID each say what happened and what to do next.
  • Never guess for the user. An ambiguous ID stops the product; it does not open a plausible folder.
  • Indigo means selection and focus. Teal means the one action worth taking. Nothing else carries colour.
  • Hover never changes what Enter opens.
  • Colour is never the only carrier of meaning: selected rows, errors, and “no link on file” each pair colour with text or shape.
